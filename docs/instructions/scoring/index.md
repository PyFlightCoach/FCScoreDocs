# Scoring a Flight

Scoring a flight takes four steps: load the flight log, set up the box, tell FCScore which schedule you flew (or mark the manoeuvres yourself), then read the results. You can score flights without an account. An account is only needed to share flights to the database.

Everything starts from the **Flight** menu (the aeroplane icon) in the top navigation bar.

1. [Load Flight Data](load_flight_data.md)
2. [Set Up The Box](box_definition.md)
3. [Define The Manoeuvres](manoeuvre_segmentation.md)
4. [Results](results.md)

Further topics:

- [Scoring one flight against several schedules](multiple_schedules.md), for recordings that contain more than one sequence or repeats of the same sequence.
- [Understanding the results](../manoeuvre_analysis/index.md), for reading the manoeuvre detail view.

Once a flight is loaded the Flight menu changes. It shows the flight source and boot time, and offers **Box**, **Manoeuvres** and (once manoeuvres exist) **Results**, plus **Clear** to unload the flight.
