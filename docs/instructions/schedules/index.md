# Schedules

A schedule is a list of manoeuvres, each defined so that FCScore can build the ideal ("template") manoeuvre, align your flight to it and score it. FCScore uses schedules from its database when you [score a flight](../scoring/index.md).

## Browsing

Open **Schedules** from the database menu (the cylinder icon) in the top navigation bar. The menu item is shown to administrators. The page lists schedules in a table with these columns:

- **Category** (a drop-down filter, for example the class or discipline),
- **Schedule** (name),
- **Type** (drop-down filter),
- an owner filter (**Me**, **Admin**, **Public** or **Anyone**),
- **Flights**, the number of flights scored against the schedule, and
- **Validity**, the dates the schedule is valid for.

Private schedules are marked with a **Private** badge.

The same table, without the extra columns, appears in the "Score flight" window when you pick the schedule(s) flown; there each row has a **Select** button.

## Opening a schedule

Click a schedule to open it in the schedule editor. You can look at the manoeuvres and see their templates in 3D, but editing is limited to the schedule's owner and administrators.
