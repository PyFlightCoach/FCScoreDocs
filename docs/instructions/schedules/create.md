# Creating a Schedule

On the **Schedules** page click **Create schedule**. A "Create schedule" window opens.

## Starting point

Optionally click **Select Aresti JSON** and choose an Aresti JSON file. Its manoeuvres and options are added to the new schedule when you press **Create**, and the window shows how many manoeuvres were read. Use **Remove** to drop the file. Without a file an empty schedule is created and you add manoeuvres afterwards.

## Properties

Set the schedule properties:

- **Rules**: the rule set (for example F3A or IMAC) that determines how it is judged.
- **Schedule Name** and, where the rule set has them, a category and other options.
- **Visibility**: **Public** or **Private**. A private schedule is only visible to its owner.
- **Type**.
- **Validity**: **From** and **To** dates.

Click **Create**. The new schedule opens in the editor, where you add the manoeuvres (see [Managing schedules](manage.md)).

The Schedules page is reached from the database menu, which lists it for administrators. If you need a schedule that is not in the database, ask an administrator.
