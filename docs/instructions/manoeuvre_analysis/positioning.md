# Positioning Downgrades

Positioning downgrades measure where the manoeuvre was flown in relation to the box and the pilot: distance, height, centring and similar. The button is labelled **Box** in the client. See [Box scoring](../../process/box.md), [visibility](../../process/visibility.md) and the [downgrade reference](../../downgrades/index.md).

Click **Box** in the manoeuvre view. Only downgrades that cost points are listed. Click a row to select it. For centring downgrades the bottom panel shows a table with the **Location** measured, the angle from the centre, the **Visibility** of the measurement and the final **Downgrade** after reduction for visibility.

The box position you set up earlier affects these scores directly. If positioning scores look wrong across the whole flight, check the [box](../scoring/box_definition.md).
