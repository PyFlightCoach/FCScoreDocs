# Inter Downgrades

Inter downgrades compare elements with each other or with the schedule, rather than judging a single element on its own. See [Inter scoring](../../process/inter.md) and the [downgrade reference](../../downgrades/index.md).

In the manoeuvre view click **inter** to list the downgrades with the points lost for each. Click a row to see it in the 3D view and read its description and judging guide text. The **Total** row is the inter score loss.
