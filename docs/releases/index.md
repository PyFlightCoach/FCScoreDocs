# Release Notes

Each FCScore release is listed here, newest first. A release note describes what changed for pilots, judges, contest organisers and partners, how scores move against the previous release, and what is known not to work yet.

Scores depend on the analysis version that produced them. The version is shown with every result, and leaderboards and competitions compare flights of one analysis version only. When a release changes how flights are scored, the notes say by how much.
