# Choose a new password

Reached from the link in the reset email. Enter a new **Password** (minimum ten characters), confirm it and press **Reset My Password**, then log in at [Login](/fcscorebase/user/login)

If the link has expired, request another at [Password reset](/fcscorebase/user/password-request)
