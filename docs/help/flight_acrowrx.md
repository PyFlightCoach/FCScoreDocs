# Load an AcroWRX file

An older address for loading an AcroWRX log. The normal route is **Flight > Create**, which recognises BIN and AcroWRX files itself.

- Select the AcroWRX file, then press **Next**.
- The flight is read and you are taken on to the analysis.
- If the file cannot be read, check it is an AcroWRX export and try again.
